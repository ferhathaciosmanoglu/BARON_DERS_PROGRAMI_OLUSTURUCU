# BARON v5.0.6 Desktop Download Center

Yeni özellik:
- Sol menüde `Masaüstü Uygulaması`
- Windows kurulum dosyası indirme ekranı
- `downloads/BARON-Setup-1.0.0.exe` bağlantısı
- Dosya mevcut değilse otomatik uyarı
- Setup Builder için ikinci indirme bağlantısı

Gerçek EXE'yi etkinleştirmek için:
1. `BARON-Setup-1.0.0.exe` dosyasını `downloads` klasörüne koyun.
2. Proje klasöründe CMD açın.
3. `firebase deploy --only hosting --force`
